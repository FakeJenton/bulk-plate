# Bulk Plate

Macro calculator, drag-and-drop daily meal builder, and weigh-in tracker in a single HTML file.

- Targets from weight, body fat, BMR (or Katch-McArdle), activity, goal, and experience
- Six-meal plate with per-food macros; drag foods between meals or in from the pantry
- Auto-adjust rescales unlocked portions to hit protein, carbs, and fat after any change
- "Close the gap" suggests foods and amounts to cover what the day is still missing
- Weekly-average weigh-ins with a hold / +200 / -200 kcal recommendation

Everything is saved in your browser (localStorage). No accounts, no server.

Open `index.html` locally or deploy the folder as a static site.
